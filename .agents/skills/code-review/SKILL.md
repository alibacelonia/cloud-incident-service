# Code review

Inspect the diff, requirements, architecture, and tests. Prioritize actionable defects over style preferences. Check correctness, input and authorization boundaries, secret handling, dependency necessity, performance risks, test coverage, and violations of established architecture.

Report findings by severity with file and line evidence, impact, and a concrete remediation. State when no findings are identified and call out residual risks or tests that were not run. Do not modify files unless explicitly asked.
